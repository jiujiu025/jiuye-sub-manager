# 小白使用说明

## 你需要准备什么

- 一台 Ubuntu 服务器。
- 一个已经解析到服务器的域名。
- Docker Engine 和 Docker Compose Plugin。
- 合法授权的上游订阅地址，或自有节点信息。

## 从零部署

1. 通过 SSH 登录 Ubuntu。
2. 安装 Docker，并确认 `docker --version` 和 `docker compose version` 可用。
3. 获取项目源码并进入项目目录。
4. 执行 `cp .env.example .env`。
5. 设置生产环境变量。密钥和管理员密码只放在服务器的 `.env`，不要写入 Git。
6. 配置 HTTPS 证书路径和域名模板，详见 `docs/Docker部署.md`。
7. 执行 `docker compose up -d --build`。
8. 用 `docker compose ps` 检查 API 和 Nginx 健康状态。

## 使用流程

1. 浏览器打开域名，登录管理员账号。
2. 来源管理中添加订阅 URL，选择自动格式或指定格式。
3. 点击来源同步，确认节点数量和同步状态。
4. 节点管理中检查节点，可禁用不需要的节点。
5. 套餐管理中创建套餐，选择来源、国家、节点类型和关键词规则。
6. 创建成功后只保存一次性显示的订阅 Token/地址。
7. 将订阅地址导入 Clash Verge Rev、Mihomo、sing-box 或支持 URI 的客户端。

## 重要安全事项

- 不要把 `.env`、数据库、Token、节点密码或 Reality 私钥上传到仓库。
- 生产环境必须使用固定且足够长度的 `JWT_SECRET_KEY`。
- 生产环境建议只通过 HTTPS 访问管理后台和订阅地址。
- 上游来源必须是你有权使用的订阅地址。
