# 常见问题

## 页面打不开

检查 Nginx 是否运行、域名 DNS 是否正确，以及 80/443 防火墙规则。使用：

```bash
docker compose ps
curl -i https://你的域名/healthz
```

## API 返回 401

管理员接口需要登录后的 Bearer JWT。确认浏览器仍有有效会话；JWT 过期后重新登录。

## 来源同步失败

先看来源详情中的错误状态，再检查容器是否能访问公网 HTTPS、DNS 是否正常、上游是否返回有效订阅。不要通过关闭 SSRF 校验来绕过错误。

## 套餐没有节点

先打开套餐预览，确认筛选规则、来源名称、国家、类型和关键词。再确认来源同步成功且节点已启用。

## 订阅格式不兼容

显式指定 `client=clash`、`client=mihomo`、`client=singbox` 或 `client=uri`。检查客户端支持的协议字段和客户端版本。

## 修改了环境变量但没有生效

Docker Compose 的环境变量在容器启动时读取。修改 `.env` 后按部署文档重新创建服务；生产环境不要在没有备份和维护窗口的情况下操作。

## 忘记 Token

Token 只在创建或重生成时显示一次。无法恢复时，在后台重生成 Token，并立即更新客户端订阅地址。
