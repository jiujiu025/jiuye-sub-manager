# 订阅使用

## 订阅接口

默认接口：

```
GET https://你的域名/sub/{token}
```

支持显式格式：

- `?client=clash`：通用 Clash YAML。
- `?client=mihomo`：Mihomo YAML。
- `?client=singbox`：sing-box JSON。
- `?client=uri`：每行一个标准 URI。

没有 `client` 时会根据 User-Agent 辅助识别，无法识别时默认 Clash YAML。

## 输出能力

Clash/Mihomo 使用 `proxies`、`proxy-groups` 和 `rules`。VLESS Reality 输出 TLS 和 Reality 参数；WebSocket 输出 WS 参数。

sing-box 输出标准 JSON，支持 VLESS、VMess、Trojan 和 Shadowsocks。URI 输出支持 VLESS、VMess、Trojan 和 Shadowsocks。

订阅响应使用对应 Content-Type，并以内联方式返回，不强制保存为随机文件名。

## 客户端

- Clash Verge Rev：使用默认地址或 `client=clash`。
- Mihomo 客户端：使用 `client=mihomo`。
- sing-box：使用 `client=singbox`。
- Shadowrocket 等 URI 客户端：使用 `client=uri`。

实际可连接性还取决于节点服务端状态、客户端版本和协议参数。
