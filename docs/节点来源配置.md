# 节点来源配置

## 来源接口

管理后台对应的 API：

- `GET /api/sources`
- `POST /api/sources`
- `GET /api/sources/{source_id}`
- `PUT /api/sources/{source_id}`
- `DELETE /api/sources/{source_id}`
- `POST /api/sources/{source_id}/sync`
- `POST /api/sources/sync-all`

这些接口需要管理员 Bearer JWT。

## 添加来源

来源需要名称、HTTP/HTTPS URL、启用状态和格式。格式可使用自动检测，也可以根据实际内容指定。URL 不允许携带用户信息，服务端会检查解析地址是否为本机、私网、链路本地、保留地址或云 metadata 地址。

同步流程会：

1. 获取上游内容。
2. 校验每次重定向目标。
3. 固定已校验的 DNS 地址。
4. 限制响应大小。
5. 解析并校验节点。
6. 在事务中替换节点。

同步失败时保留上一次成功节点，不会因为一次上游异常清空节点池。

## 来源排错

检查来源详情中的状态、最近同步时间、节点数量和错误信息。重点区分：

- HTTP 状态码错误。
- DNS/TLS/连接错误。
- 内容为空或超过大小限制。
- 内容不是支持的订阅格式。
- 节点字段校验失败。

只添加你有权限使用的来源。
