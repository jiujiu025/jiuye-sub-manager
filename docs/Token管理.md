# Token 管理

## Token 生命周期

套餐创建时生成高强度订阅 Token。后台只在创建或重生成响应中返回一次明文 Token，数据库保存哈希，后台展示地址使用加密存储值。

Token 不是管理员 JWT，两者用途不同：

- 管理员 JWT：访问管理 API。
- 套餐 Token：访问公开订阅接口。

## 操作

- 重生成 Token：旧 Token 立即失效，新 Token 只在响应中返回一次。
- 撤销 Token：当前 Token 立即失效，不返回订阅内容。
- 禁用套餐：订阅请求被拒绝。

请把订阅 Token 当作密码处理，不要放在公开日志、截图、Issue 或仓库中。若疑似泄露，立即重生成或撤销。
