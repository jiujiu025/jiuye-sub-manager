# 套餐管理

## 套餐是什么

套餐不复制节点内容，只保存节点筛选和展示规则。订阅请求时根据当前节点池动态生成内容。

支持的规则摘要包括：

- 来源筛选
- 节点 ID
- 国家筛选
- 节点类型
- 包含关键词
- 排除关键词
- 重命名
- 排序

## API

- `GET /api/packages`
- `POST /api/packages`
- `GET /api/packages/{package_id}`
- `PUT /api/packages/{package_id}`
- `DELETE /api/packages/{package_id}`
- `GET /api/packages/{package_id}/preview`
- `POST /api/packages/{package_id}/toggle`

创建或修改套餐后，先使用预览确认命中节点，再复制订阅地址。

套餐禁用后订阅返回拒绝结果。没有可用节点时，订阅不会输出空的假配置，而是返回业务错误。
